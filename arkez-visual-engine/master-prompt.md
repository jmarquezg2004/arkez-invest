# Prompt maestro

Crea una experiencia tecnoeditorial de educación financiera para la marca, idioma y tema especificados. Usa azul marino institucional para contexto, marfil y blanco para lectura, y dorado para transiciones y acciones. Usa Manrope Variable y un sistema coherente de iconos. Compón las ilustraciones cinematográficas con objetos en perspectiva, luz de borde localizada y sombras de contacto. Deja un área de bajo contraste detrás del texto.

Conserva los controles y las cifras como elementos semánticos y verificables. Usa títulos, legendas, periodos, unidades y atribución. Especifica conducta móvil y movimiento reducido. Entrega componentes reutilizables, archivos optimizados y una prueba visual del resultado.
